Step 1 — Migration 052 (backend/db_migrations.py)
Append a new migration. Do not edit migration 050.
sql-- 052: avtd_role default + NOT NULL
ALTER TABLE solcon_engagements
  ALTER COLUMN avtd_role SET DEFAULT 'supplier';

UPDATE solcon_engagements
  SET avtd_role = 'supplier'
  WHERE avtd_role IS NULL;

ALTER TABLE solcon_engagements
  ALTER COLUMN avtd_role SET NOT NULL;
The UPDATE is belt-and-braces — migration 050 should have caught everything, but new rows could have been inserted between then and now with NULL. Run the UPDATE before the SET NOT NULL or the ALTER will fail.
