## STEP 1 — Convert and save images

The following 7 competitor images need to be saved to 
backend/photo_report/references/ as .jpg files.
They are currently in /mnt/user-data/uploads/ as .webp files.

Run this Python script to convert and copy them:

```python
from PIL import Image
import pathlib

uploads = pathlib.Path("/mnt/user-data/uploads")
refs = pathlib.Path("backend/photo_report/references")

conversions = [
    ("382030308.webp",  "aliko_cognac_competitor.jpg"),
    ("269257695.webp",  "aliko_wine_competitor.jpg"),
    ("308935895.webp",  "koblevo_cognac_competitor.jpg"),
    ("345033198.webp",  "khortytsia_vodka_competitor.jpg"),
    ("478890389.webp",  "koblevo_wine_muscat_competitor.jpg"),
    ("659263268.webp",  "koblevo_wine_cabernet_competitor.jpg"),
    ("388502306.webp",  "hlibnydar_vodka_competitor.jpg"),
]

for src_name, dst_name in conversions:
    src = uploads / src_name
    dst = refs / dst_name
    img = Image.open(src).convert("RGB")
    img.save(dst, "JPEG", quality=90)
    print(f"✅ {dst_name} saved ({dst.stat().st_size // 1024}KB)")
```
