## Changes to scoring.py

### Fix 1: POS_MISSING — check AVTD shelf strip independently

Current code only flags POS when competitor has POS AND we don't:
```python
if pos.get("competitor_branded_pos_present") and not pos.get("avtd_shelf_strip_present"):
```

Olena flags when AVTD has NO shelf strip at all — regardless of competitors. This is 153 fails (31% of all fails!).

**Change:** Add a separate check for missing AVTD shelf strip:

```python
    # Existing check: competitor POS present but no AVTD shelf strip
    pos = vision_data.get("pos_materials", {})
    if pos.get("competitor_branded_pos_present") and not pos.get("avtd_shelf_strip_present"):
        score -= 10
        errors.append({
            "code": "POS_COMPETITOR",
            "description": "Відсутній шелфстрипер AVTD при наявності конкурентських POS",
            "brand": "AVTD",
            "severity": "standard",
        })
    
    # NEW: AVTD shelf strip missing (regardless of competitor POS)
    # This is Olena's #1 fail reason (153 out of 486 fails)
    elif not pos.get("avtd_shelf_strip_present"):
        score -= 5  # Lower penalty than competitor POS case
        errors.append({
            "code": "POS_MISSING",
            "description": "Відсутній шелфстрипер/POS-матеріали AVTD",
            "brand": "AVTD",
            "severity": "standard",
        })
```

### Fix 2: Cognac/Wine/Sparkling share failures as ERRORS (not just info)

Currently cognac/wine/sparkling shares are calculated but never generate errors — they're info-only. Olena fails reports for low cognac share (13 fails) and wine share (10 fails).

**Add after the sparkling calculation section, before the standard_errors_count line:**

```python
    # === PHASE 2 SHARE CHECKS (scored as standard errors) ===
    # Olena fails reports for cognac <33%, wine <40%, sparkling <20%
    
    if cognac_share is not None and total_cognac > 0 and cognac_share < 33:
        score -= 5
        errors.append({
            "code": "COGNAC_SHARE_FAIL",
            "description": f"Частка полиці коньяку {cognac_share}% < 33%",
            "brand": "AVTD Коньяк",
            "severity": "standard",
        })
    
    if wine_share is not None and total_wine > 0 and wine_share < 40:
        score -= 5
        errors.append({
            "code": "WINE_SHARE_FAIL",
            "description": f"Частка полиці вина {wine_share}% < 40%",
            "brand": "AVTD Вино",
            "severity": "standard",
        })
    
    if sparkling_share is not None and total_sparkling > 0 and sparkling_share < 20:
        score -= 5
        errors.append({
            "code": "SPARKLING_SHARE_FAIL",
            "description": f"Частка полиці ігристого {sparkling_share}% < 20%",
            "brand": "AVTD Ігристе",
            "severity": "standard",
        })
```

## Important: Phase 2 scoring impact

Adding cognac/wine/sparkling errors means more reports will FAIL. This is correct — it aligns with Olena's standards. But expect pass rate to drop from ~80% to ~60-65%.

The -5 penalty for each category share fail is intentionally lower than vodka (-15 auto_fail) because:
1. Wine/cognac/sparkling detection is less accurate than vodka (12% vs 21-25% dev)
2. Olena's Д25 threshold may not match our AI threshold exactly
3. We can increase penalties after calibration confirms accuracy
