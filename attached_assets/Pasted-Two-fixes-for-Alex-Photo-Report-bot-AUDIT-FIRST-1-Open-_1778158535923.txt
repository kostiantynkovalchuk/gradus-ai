## FIX 1 — Pre-capture instruction before photo request

When agent taps "📸 Новий звіт", BEFORE asking for photos,
send this instruction message:

```python
PHOTO_INSTRUCTIONS = """📸 Як правильно сфотографувати полицю:

1️⃣ *Загальний огляд* — стань за 1.5–2м
Вся алкогольна секція в кадрі

2️⃣ *Горілка* — крупний план полиці з горілкою
Етикетки мають бути чітко читабельні

3️⃣ *Коньяк / Вино / Ігристе* — окреме фото кожного
Тільки якщо є на полиці, крупний план

⛔ *Не підходить:*
- Фото з кута або від каси
- Занадто далеко — етикетки нечіткі
- Темно або засвічено спалахом

Надішли 2–5 фото 👇"""
```

Send this message with reply_markup=ReplyKeyboardRemove() 
to clear any existing keyboard — agent just sends photos directly after.

Do NOT add a confirmation button — just send the instruction 
and immediately move to COLLECTING_PHOTOS state.
Fewer taps = better field UX.

```python

vodka_share = result.get('shelf_share', {}).get('vodka', {}).get('percent', 0) or 0
```
