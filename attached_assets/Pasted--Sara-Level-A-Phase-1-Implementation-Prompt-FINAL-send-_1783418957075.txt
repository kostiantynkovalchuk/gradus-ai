═══ STEP 3 — WebSocket protocol (browser ↔ our server) ═══
Single WS at /ws/session?token=...
Client → server: JSON {"type":"start","sample_rate":16000}, then binary
frames of PCM16 mono mic audio; {"type":"end_session"}.
Server → client:
  {"type":"partial_transcript","text":...}       (live, uncommitted)
  {"type":"user_transcript","text":...}          (VAD-committed final)
  {"type":"assistant_delta","text":...}          (Claude tokens, live)
  binary frames: TTS audio chunks (pick mp3_44100_128 or pcm_24000 and
                 document the choice in eleven_ws.py)
  {"type":"turn_complete","metrics":{...}}
  {"type":"error","message":...}
Rule 3 applies: NEVER fail silently. Every leg failure must surface as
an error event to the client AND a logged exception. A dropped
STT/TTS/Claude connection closes the turn cleanly and leaves the
session usable for the next turn.

pipeline.
