## FIX 1 — Competitor reference images

### Step 1 — Download competitor reference images
Run this Python script to download reference images for 
the two main competitors that cause false positives:

```python
import httpx, pathlib

refs_dir = pathlib.Path("backend/photo_report/references")

# Nemiroff — Ukraine's #1 vodka competitor
# Distinctive: black/dark label, NEMIROFF text, wheat logo
nemiroff_url = "https://nemiroff.ua/upload/iblock/nemiroff-vodka.jpg"

# Villa Krim — wine competitor confused with Villa UA  
# Distinctive: similar bottle shape to Villa UA but different label
villakrim_url = "https://villakrim.ua/image/catalog/wine.jpg"

for name, url in [("nemiroff_competitor.jpg", nemiroff_url), 
                   ("villakrim_competitor.jpg", villakrim_url)]:
    try:
        r = httpx.get(url, timeout=10, follow_redirects=True)
        if r.status_code == 200:
            (refs_dir / name).write_bytes(r.content)
            print(f"✅ {name} downloaded")
        else:
            print(f"❌ {name} failed: {r.status_code}")
    except Exception as e:
        print(f"❌ {name} error: {e}")
```

### Retry logic for low-share:
When low-share retry triggers:
1. Run the existing category retry function 
   (same as 0-count retry)
2. If retry returns HIGHER AVTD count → use retry result
3. If retry returns same or lower → keep original
4. Log result as: "[PhotoReport] Low-share retry improved 
   vodka: 25% → 61%" or "did not improve"

### Important — retry budget:
Low-share retry uses same max_tokens as category retry (1024).
Do NOT increase max_tokens for low-share retries.

### Retry ordering — place low-share checks AFTER 
existing 0-count retries, BEFORE calculate_score() call.
