Three improvements for Pulse dashboard + Telegram alerts.

=== FIX 1: Department names cut off in bar chart ===

The "Настрій за відділами" horizontal bar chart cuts off long department names 
like "Департамент производства; Отдел поставок".

In the Chart.js config for the department mood chart, increase the left padding:

options: {
  indexAxis: 'y',
  layout: {
    padding: { left: 20 }
  },
  scales: {
    y: {
      ticks: {
        autoSkip: false,
        font: { size: 11 },
        // Truncate labels longer than 40 chars
        callback: function(value) {
          const label = this.getLabelForValue(value);
          return label.length > 40 ? label.substring(0, 37) + '...' : label;
        }
      }
    }
  }
}

Also increase the chart container height dynamically based on number of departments:
  const chartHeight = Math.max(400, departments.length * 35);
  canvas.parentElement.style.height = chartHeight + 'px';

=== FIX 2: Clickable trigger cards showing employee names ===

In the "Тригери цього місяця" section, each trigger card (Робоче навантаження 5, 
Комунікація з колегами 2, etc.) should be clickable.

On click → expand to show list of employees who triggered it this month.

Implementation:
a) Add a new endpoint:
   GET /hr/api/pulse-trigger-details?type={trigger_type}&month={YYYY-MM}
   
   Returns:
   {
     "trigger_type": "survey_tasks",
     "employees": [
       {"name": "Дятченко Мария Сергеевна", "department": "Департамент маркетинга", "date": "2026-05-13"},
       {"name": "Іванов Олексій", "department": "Департамент продаж; ПП Дніпро", "date": "2026-05-13"},
       ...
     ]
   }

   SQL:
   SELECT employee_name, department, fired_at::date as date
   FROM pulse_triggers
   WHERE trigger_type = :type
     AND fired_at >= date_trunc('month', CURRENT_DATE)
   ORDER BY fired_at DESC

b) In the HTML, make each trigger card clickable:
   <div class="trigger-card" onclick="loadTriggerDetails('survey_tasks')" style="cursor:pointer;">

c) On click, show a small table/list below the card:
   <div id="triggerDetails_survey_tasks" style="display:none;">
     <table>
       <tr><td>Дятченко М.С.</td><td>Деп. маркетинга</td><td>13.05</td></tr>
       ...
     </table>
   </div>

d) Toggle: click again → hide the list.

=== FIX 3: Interactive employee name in Telegram alerts ===

In the HR alert message (alert_hr_team_identified and alert_hr_pulse_problem),
make the employee name a clickable link that opens their Telegram profile.

Telegram supports deep links: tg://user?id={telegram_id}
In HTML parse mode this is: <a href="tg://user?id={tid}">{name}</a>

But since we send without parse_mode (plain text), we need to switch to HTML:

Change the alert sending to use parse_mode="HTML":

alert_text = (
    f'🔴 Пульс команди — Попередження\n\n'
    f'👤 <a href="tg://user?id={employee_telegram_id}">{employee_name}</a>\n'
    f'🏢 Відділ: {department}\n'
    f'📌 Проблема: {category_label}\n'
    f'📊 Самопочуття: 💔 перевантаження\n\n'
    f'💬 Зверніться до співробітника конфіденційно'
)

Send with parse_mode="HTML" in the httpx POST body.

IMPORTANT: When using HTML parse_mode, escape any < > & in employee names:
  import html
  safe_name = html.escape(employee_name)

This works in both alert_hr_team_identified() and alert_hr_pulse_problem().
The employee_telegram_id is available (it's the employee_id/chat_id used throughout).
