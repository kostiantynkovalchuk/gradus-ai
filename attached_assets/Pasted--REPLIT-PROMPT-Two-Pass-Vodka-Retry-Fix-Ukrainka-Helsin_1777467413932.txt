# REPLIT PROMPT: Two-Pass Vodka Retry — Fix Ukrainka/Helsinki Under-Detection

## Problem

Data from 50 expert corrections shows that in 7 out of 11 HIGH confidence vodka reports, AI finds GreenDay but reports Ukrainka=0 and Helsinki=0 — even when expert confirms they ARE present. This causes 25% average deviation at high confidence (worse than medium confidence at 12.7%).

Examples:
- Report #56: AI found GD:22, UA:0, HEL:0 → expert says vodka share is 100% (not 63%)
- Report #58: AI found GD:15, UA:0, HEL:0 → expert says 68% (not 43%)
- Report #52: AI found GD:6, UA:0, HEL:0 → expert says 50% (not 60%)

Root cause: GreenDay is easy to spot (bright green bottles), but Ukrainka (transparent, white label) and Helsinki (transparent, winter scene) blend in and get missed even when Claude is "confident".

## Solution: Automatic Vodka Retry

After the initial analysis, if GreenDay > 0 but Ukrainka + Helsinki = 0, automatically run a SECOND focused pass specifically looking for Ukrainka and Helsinki.

## Implementation

In `vision.py`, find the function that orchestrates the analysis (likely `analyze_photos` or similar). After the initial Claude Vision call returns results, add this logic:

```python
# After initial analysis returns `result` dict:

vodka = result.get("vodka", {})
gd = vodka.get("greenday_facings") or 0
ua = vodka.get("ukrainka_facings") or 0
hel = vodka.get("helsinki_facings") or 0

# TRIGGER: GreenDay found but Ukrainka + Helsinki = 0
# This pattern is wrong 70% of the time based on expert data
if gd > 0 and ua == 0 and hel == 0:
    logger.info(f"[PhotoReport] Vodka retry triggered: GD={gd} but UA+HEL=0")
    
    retry_result = _retry_ukrainka_helsinki(client, photo_b64_list)
    
    if retry_result:
        # Merge retry findings into original result
        retry_ua = retry_result.get("ukrainka_facings") or 0
        retry_hel = retry_result.get("helsinki_facings") or 0
        
        if retry_ua > 0 or retry_hel > 0:
            logger.info(f"[PhotoReport] Retry found: UA={retry_ua}, HEL={retry_hel}")
            vodka["ukrainka_facings"] = retry_ua
            vodka["helsinki_facings"] = retry_hel
            
            # Recalculate our total and share
            other_avtd = vodka.get("other_avtd_vodka_facings") or 0
            new_our = gd + retry_ua + retry_hel + other_avtd
            total = vodka.get("total_vodka_facings") or 0
            
            # Update total if retry found bottles AI missed
            if new_our > (vodka.get("our_facings") or 0):
                additional = new_our - (gd + other_avtd)  # newly found bottles
                vodka["total_vodka_facings"] = total + additional
                vodka["our_facings"] = new_our
            
            result["vodka"] = vodka
            
            # Add note about retry
            notes = result.get("notes", "")
            result["notes"] = notes + " [Vodka retry: found additional Ukrainka/Helsinki after initial scan missed them]"
```

## New Retry Function

Add this function to `vision.py`:

```python
def _retry_ukrainka_helsinki(client, photo_b64_list: list[str]) -> dict | None:
    """Focused second pass specifically looking for Ukrainka and Helsinki.
    
    Triggered when GreenDay is found but Ukrainka + Helsinki = 0,
    which is wrong 70% of the time based on expert corrections.
    """
    
    RETRY_PROMPT = """You are re-analyzing a shelf photo. The first analysis found GreenDay vodka but MISSED Ukrainka and Helsinki.

Your ONLY task: find Ukrainka and Helsinki bottles on these shelves. Ignore everything else.

UKRAINKA (Українка) — what to look for:
- TRANSPARENT/CLEAR glass bottles (not green like GreenDay)
- Wide WHITE label with large Cyrillic text "УКРАЇНКА" 
- Diamond/geometric pattern carved into the glass on some variants
- Silver/grey metal cap
- Variants that ALL count as Ukrainka:
  * Traditional — white label, clear bottle
  * Crystal — silver/diamond label, clear bottle with geometric pattern
  * Tinctures (настоянки) — colored liquid (red=berry, green=herb, dark=black currant) but SAME bottle shape and "УКРАЇНКА" text
- Usually stands in groups of 3-6 bottles
- Often positioned NEAR GreenDay on the same shelf row

HELSINKI (Хельсінкі) — what to look for:
- TRANSPARENT/CLEAR glass bottles (similar to Ukrainka but different label)
- Winter/mountain landscape scene on label
- Text "HELSINKI" in Latin letters
- 5 different label colors: light blue (Ice Palace), grey (Winter Capital), dark blue (Ultramarin), orange (Frosty Citrus), brown (Salted Caramel)
- Often stands NEXT TO GreenDay
- Do NOT confuse with Klinkov dark boxes — Helsinki is always a transparent BOTTLE

Scan EVERY shelf row carefully. Count each facing.

Return ONLY this JSON:
{
  "ukrainka_facings": 0,
  "ukrainka_variants": [],
  "helsinki_facings": 0,
  "helsinki_variants": [],
  "search_notes": "describe where you looked and what you found"
}"""

    content = []
    
    # Add reference images for Ukrainka and Helsinki only
    from photo_report.references import BRAND_REFERENCES
    for ref in BRAND_REFERENCES:
        name = ref.get("name", "")
        if any(k in name for k in ["ukrainka", "helsinki"]):
            content.append({
                "type": "image",
                "source": {"type": "base64", "media_type": ref["media_type"], "data": ref["b64"]}
            })
            content.append({
                "type": "text",
                "text": f"REFERENCE: {ref['label']}"
            })
    
    # Add shelf photos
    content.append({
        "type": "text",
        "text": "Now look at these shelf photos and find Ukrainka and Helsinki:"
    })
    
    for b64 in photo_b64_list:
        content.append({
            "type": "image",
            "source": {"type": "base64", "media_type": "image/jpeg", "data": b64}
        })
    
    content.append({
        "type": "text",
        "text": RETRY_PROMPT
    })
    
    try:
        raw = _call_claude_vision(
            client=client,
            content=content,
            system="You are a shelf photo analyzer. Return only valid JSON.",
            max_tokens=1024,
        )
        
        result = json.loads(raw)
        logger.info(f"[PhotoReport] UA/HEL retry result: UA={result.get('ukrainka_facings')}, HEL={result.get('helsinki_facings')}, notes={result.get('search_notes', '')[:100]}")
        return result
        
    except Exception as e:
        logger.error(f"[PhotoReport] UA/HEL retry failed: {e}")
        return None
```

## Key Design Decisions

1. **Only Ukrainka/Helsinki references sent in retry** — not all 23 images. This saves tokens and focuses Claude's attention. ~4 reference images (ukrainka_traditional, ukrainka_lineup, helsinki_ice_palace, helsinki_lineup) instead of 23.

2. **Retry ONLY triggers when GD > 0 and UA + HEL = 0** — this specific pattern is wrong 70% of the time. We don't retry when GD = 0 (wide-angle problem) or when UA/HEL > 0 (already detected).

3. **Merge logic adds to total** — if retry finds 5 Ukrainka, total_vodka_facings increases by 5 (these bottles were missed in first pass).

4. **Cost: ~$0.03 extra per triggered retry** — only ~40% of reports will trigger this (when GD found but UA/HEL=0). Average cost increase: ~$0.01 per report.
