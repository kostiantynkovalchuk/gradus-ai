=== FIX 2: Position dropdown with search history ===

Replace the plain text input for "Посада" with a datalist-backed input 
that remembers past searches.

Implementation:
1. On page load, fetch saved positions from localStorage:
   const savedPositions = JSON.parse(localStorage.getItem('salarySearchHistory') || '[]');

2. Create a <datalist> with saved positions:
   <input list="positionHistory" id="salaryPosition" placeholder="Торговий представник">
   <datalist id="positionHistory">
     <option value="Торговий представник">
     <option value="Вантажник">
     ...
   </datalist>

3. After each successful search, save the position to localStorage:
   function saveSalarySearch(position) {
     let history = JSON.parse(localStorage.getItem('salarySearchHistory') || '[]');
     if (!history.includes(position)) {
       history.unshift(position);  // newest first
       if (history.length > 20) history = history.slice(0, 20);  // cap at 20
       localStorage.setItem('salarySearchHistory', JSON.stringify(history));
     }
     updatePositionDatalist();
   }

4. Call saveSalarySearch(position) inside searchSalary() after successful fetch.

5. Also pre-populate with common AVTD positions:
   const DEFAULT_POSITIONS = [
     'Торговий представник', 'Вантажник', 'Мерчандайзер', 
     'Комірник', 'Водій', 'Супервайзер', 'Бухгалтер'
   ];
   On first load (empty localStorage), seed with these defaults.

This gives HR a dropdown that grows smarter with usage — 
no typing needed for repeat searches.
