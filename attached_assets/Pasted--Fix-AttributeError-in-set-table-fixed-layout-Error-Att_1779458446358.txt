# Fix: AttributeError in `_set_table_fixed_layout`

**Error:** `AttributeError: 'CT_Tbl' object has no attribute 'get_or_add_tblPr'`
**File:** `backend/solomon_contracts/artifacts.py`, line 168
**Caller:** `build_protocol_docx()` at line 388
**Impact:** All protocol DOCX generation requests return HTTP 500.

## Root cause

`python-docx` exposes `get_or_add_*` helpers on **some** `CT_*` XML element classes but not all. `CT_Tbl` (the table element) doesn't have one for `tblPr`. The helper has to be implemented manually: look for the existing `<w:tblPr>` child element, and if absent, create and insert it as the first child (it must be the first child of `<w:tbl>` per OOXML schema).

## Fix

Replace the body of `_set_table_fixed_layout` with this:

```python
from docx.oxml import OxmlElement
from docx.oxml.ns import qn


def _set_table_fixed_layout(tbl_el, col_widths_dxa):
    """
    Force fixed table layout — column widths become authoritative,
    Word will not auto-expand columns to fit content.

    Args:
        tbl_el: the CT_Tbl XML element (table._element from a python-docx Table)
        col_widths_dxa: list of column widths in DXA (twentieths of a point)
    """
    # 1. Find or create <w:tblPr> as the first child of <w:tbl>
    tblPr = tbl_el.find(qn('w:tblPr'))
    if tblPr is None:
        tblPr = OxmlElement('w:tblPr')
        tbl_el.insert(0, tblPr)

    # 2. Remove any existing <w:tblLayout> in tblPr, then add fixed layout
    for existing in tblPr.findall(qn('w:tblLayout')):
        tblPr.remove(existing)
    tblLayout = OxmlElement('w:tblLayout')
    tblLayout.set(qn('w:type'), 'fixed')
    tblPr.append(tblLayout)

    # 3. Find or create <w:tblGrid> right after <w:tblPr>
    #    (must come after tblPr but before any <w:tr> rows)
    tblGrid = tbl_el.find(qn('w:tblGrid'))
    if tblGrid is None:
        tblGrid = OxmlElement('w:tblGrid')
        # Insert after tblPr (index of tblPr + 1)
        tblPr_index = list(tbl_el).index(tblPr)
        tbl_el.insert(tblPr_index + 1, tblGrid)
    else:
        # Clear existing gridCol entries so we can rebuild
        for existing in tblGrid.findall(qn('w:gridCol')):
            tblGrid.remove(existing)

    # 4. Add one <w:gridCol w:w="..."/> per column
    for width_dxa in col_widths_dxa:
        gridCol = OxmlElement('w:gridCol')
        gridCol.set(qn('w:w'), str(width_dxa))
        tblGrid.append(gridCol)
```

## Why the three steps matter

- **tblPr first**: OOXML schema requires `<w:tblPr>` as the first child of `<w:tbl>`. Inserting it anywhere else makes the document non-conformant; some renderers (notably Word strict mode) reject the file.
- **tblLayout removal before insert**: idempotent — calling `_set_table_fixed_layout` twice doesn't accumulate duplicate `tblLayout` elements.
- **tblGrid required**: without it, fixed layout has nothing to read for column widths and Word falls back to auto-sizing. The agent's previous attempt may have skipped this — confirm tblGrid is being populated correctly.
