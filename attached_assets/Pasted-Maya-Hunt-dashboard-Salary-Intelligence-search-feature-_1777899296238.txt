=== PART 2: Backend endpoint ===

Create new endpoint:

GET /hr/api/salary-search?position={}&city={}

This endpoint:

1. Calls Robota.ua GraphQL (real-time, not cached):
   - Use existing robotaua_salary.py fetch logic
   - Pass position + city as keywords
   - Return: vacancy median, candidate median, counts, timeseries

2. Calls Work.ua search (existing hunt_workua_scraper.py logic):
   - Search by position + city
   - Return: count of CVs found (no salary data)
   - Do NOT scrape full CVs — just get the count from search results page

3. Queries Telegram data (from hunt_candidates table):
   - SELECT salary_expectation_uah FROM hunt_candidates 
     WHERE position ILIKE '%{position}%' AND city ILIKE '%{city}%'
     AND created_at > NOW() - INTERVAL '6 months'
   - Calculate: min, max, median of salary_expectation_uah
   - Return: count, min, max, median

4. Return combined JSON:

=== PART 5: JavaScript ===

In the dashboard HTML, add:

function searchSalary() {
    const position = document.getElementById('salaryPosition').value.trim();
    const city = document.getElementById('salaryCity').value.trim();
    if (!position) return;
    
    // Show loading
    document.getElementById('salaryResults').innerHTML = 'Завантаження...';
    document.getElementById('salaryResults').style.display = 'block';
    
    fetch(`/hr/api/salary-search?position=${encodeURIComponent(position)}&city=${encodeURIComponent(city)}`)
    .then(r => r.json())
    .then(data => renderSalaryResults(data))
    .catch(e => { document.getElementById('salaryResults').innerHTML = 'Помилка завантаження'; });
}

renderSalaryResults(data) should populate all the cards described above.
Use Chart.js for the timeseries chart (same library already loaded on page).
