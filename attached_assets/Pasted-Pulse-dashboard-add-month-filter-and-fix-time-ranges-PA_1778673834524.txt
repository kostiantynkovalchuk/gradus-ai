Pulse dashboard — add month filter and fix time ranges.

=== PART 1: Add month dropdown to Pulse tab ===

Add a month selector at the top of the Pulse tab content (before KPI cards):

<select id="pulseMonthFilter" onchange="loadPulseData()">
  <!-- Populate dynamically with last 6 months -->
</select>

On page load, populate with months from current back to 6 months ago:
  2026-05 (поточний)
  2026-04
  2026-03
  ...

Default: current month selected.

=== PART 2: Pass month to all Pulse API calls ===

Update loadPulseData() to read the selected month and pass to all endpoints:

const month = document.getElementById('pulseMonthFilter').value;

fetch(`/hr/api/pulse-overview?month=${month}`)
fetch(`/hr/api/pulse-alerts?month=${month}`)
fetch(`/hr/api/pulse-videos?month=${month}`)
fetch(`/hr/api/pulse-trigger-details?type=${type}&month=${month}`)

=== PART 3: Update backend endpoints to accept month parameter ===

All pulse endpoints should accept optional ?month=YYYY-MM parameter.

/hr/api/pulse-overview:
- If month provided: filter pulse_surveys by survey_month = month
- Filter triggers by: to_char(fired_at, 'YYYY-MM') = month
- Default (no month): current month

/hr/api/pulse-trigger-details:
- Change from: fired_at >= NOW() - INTERVAL '30 days'
- Change to: to_char(fired_at, 'YYYY-MM') = :month
- This way April triggers show in April, May in May — no mixing

/hr/api/pulse-alerts:
- Filter by month if provided

/hr/api/pulse-videos:
- Filter viewed_at by month if provided

=== PART 4: Make trigger counts consistent with month ===

The trigger count in pulse-overview AND the detail list in pulse-trigger-details
must use the SAME month filter. Both should filter by:
  to_char(fired_at, 'YYYY-MM') = :month

No more rolling 30-day window — use exact month boundaries.

=== PART 5: Hide the top-level "7 днів / Оновити" filter on Pulse tab ===

The global period filter (7 days, 30 days, etc.) is irrelevant for Pulse 
since it has its own month filter. When Pulse tab is active:
- Either hide the global filter
- Or ignore it (Pulse uses its own month dropdown only)

Simplest: just ignore it. Pulse data always uses its own month selector.
